## 1. Quick Overview & Key Principles

PathCraft AI operates on three core principles:
1. **100% Authentic Preservation**: We never invent synthetic companies, fake dates, or hallucinated job titles. Your real career history is strictly preserved.
2. **Live Market Grounding**: Requirements are not pulled from a static list; they are fetched dynamically from live 2026 hiring trends via Google Search Grounding.
3. **Evidence-Based Semantic Matching**: Your skills are verified across your entire resume context—including active work bullets, project tech stacks, certifications, and GitHub repositories.

## 2. Hub 1: Skill Gap Diagnostic & Candidate Differentiators

### How to Use Hub 1
1. **Select or Type Target Role**: Choose from modern technical roles (e.g., *GenAI / LLM Systems Engineer, Data & AI Platform Engineer, MLOps Engineer*) or type any custom specialty.
2. **Select Seniority & Study Budget**: Choose from *Entry-Level, Mid-Level, Senior, or Staff/Principal*, and select your weekly commitment (e.g. *10 hrs/week*).
3. **Upload Resume or Paste Text**: Upload your multi-page PDF resume or paste raw text.
4. **(Optional) Enter GitHub & LinkedIn**: Add your GitHub username and paste any LinkedIn honors or achievements.
5. **Run Analysis**: Click **"🚀 Run Complete Career Copilot Pipeline"** (or **"🔍 Step 1: Parse Profile"**).

### What Hub 1 Delivers
- **🌟 Key Differentiators**: Advanced technical skills found in your profile (e.g. *LangGraph, RAG, GenSQL, Terraform, Kubernetes*).
- **💡 High-Synergy Alternate Roles**: Top 2–3 alternative job titles where your existing background gives you a competitive advantage, complete with match percentage and specific rationale.
- **🐙 Verified GitHub Profile**: Automatically inspects your public repositories, star counts, and language distribution.
- **2-Tier Match Breakdown**:
  - **Overall Weighted Match**: $70\%$ Core Must-Haves + $30\%$ Advanced Differentiators.
  - **Core Skills Match**: Non-negotiable foundational requirements.
- **Semantic Evidence Table**: Shows the exact bullet point, project, or certificate that verified each required skill.

## 3. Hub 2: Authentic In-Place Resume Optimizer

### How to Use Hub 2
1. **Inspect ATS Score Improvements**: Review your **Original ATS Score** vs. **Optimized ATS Score** and click **"🔍 View Detailed ATS Audit Breakdown"** to view scores across Formatting, Keyword Match, Impact, and Section Completeness.
2. **Review What Was Improved**: See the exact bullets rewritten using Google's XYZ formula:
   > *"Accomplished [X] as measured by [Y], by doing [Z]"*
3. **Inspect the Side-by-Side Diff View**:
   - **Original Resume (Left)**: Highlights removed/rephrased lines in soft red.
   - **Optimized Resume (Right)**: Highlights newly incorporated power bullets and keywords in soft green with green border accents.
4. **Toggle Revert if Desired**: Turn on the **"Use Original Resume"** toggle if you want to download or edit your unmodified original version.
5. **Edit & Finalize**: Directly edit the resume text inside the in-browser editor. All changes are saved automatically for your session.
6. **Download Executive PDF**: Click **"Download Resume as PDF"** to get an executive-styled PDF formatted with clean typography, navy section headers, contact bars, and ATS-compliant hierarchy.

## 5. Hub 4: AI Mock Interview Simulator

### How to Use Hub 4
1. **Configure Difficulty & Length**: Select 3, 5, or 10 questions and pick your target seniority (*Mid-Level, Senior, Staff*).
2. **Start Interview**: Click **"🚀 Start Mock Technical Interview"**.
3. **Answer Scenario-Based Questions**: Questions are targeted: $70\%$ focus on your missing skill gaps and $30\%$ test system design and core strengths.
4. **Instant Turn-by-Turn Feedback**: For every answer you submit, receive:
   - Numerical Score ($0–100$)
   - Constructive Feedback on strengths & missing nuances
   - Key Takeaway for real interviews
   - Production Model Answer Snippet
5. **Final Scorecard**: Receive an overall average score, Hiring Readiness tier (*🟢 Strong Hire / Staff Ready, 🟡 Hire / Solid Mid-Senior, 🟠 Needs Dedicated Upskilling*), and performance summary.

## 6. Human-in-the-Loop (HITL) Controls

The **Skill Correction Panel** is located at the bottom of Hub 1 in an expandable panel:
- **Add Unlisted Skills**: If you have hands-on experience in a tool that wasn't in your text, type it into the input box and click **"Add Skill"**.
- **Remove Misidentified Skills**: Uncheck any skill from the multi-select dropdown.
- **Re-run Diagnostic**: Click **"Re-run Skill Gap Analysis with Updated Skills"** to re-score your match percentage and update all downstream hubs instantly.

## 7. Enterprise ATS Evaluation Rubric

PathCraft AI calculates ATS compatibility using a **100-Point 4-Dimension Rubric**:

| Pillar | Max Pts | Focus Areas |
|---|:---:|---|
| **Keyword Match** | **35 pts** | Target skills present in active work bullets ($1.0\times$ weight), projects ($0.8\times$), or skills list ($0.5\times$). |
| **Impact & Metrics** | **25 pts** | Action verbs (*Engineered, Architected, Reduced, Deployed*) + quantified metrics ($\%$, latency, scale, volume). |
| **Formatting & Structure** | **25 pts** | Recognizable standard headers (`EXPERIENCE`, `EDUCATION`, `SKILLS`, `PROJECTS`), clean linear single-column layout. |
| **Section Completeness** | **15 pts** | Complete presence of contact details, work history, education, projects, and certifications. |

## 8. Google Cloud Run Serverless Deployment

PathCraft AI is containerized and ready for 1-click deployment to **Google Cloud Run (Serverless)**.

### Quick Deploy Command
```bash
# 1. Authenticate with Google Cloud
gcloud auth login
gcloud config set project YOUR_PROJECT_ID

# 2. Deploy Streamlit Web UI to Cloud Run
gcloud run deploy pathcraft-ai \
    --source . \
    --region us-central1 \
    --platform managed \
    --allow-unauthenticated \
    --set-env-vars GOOGLE_API_KEY="your_api_key_here" \
    --memory 2Gi \
    --cpu 2 \
    --min-instances 0 \
    --max-instances 10
```

*(See [README.md](README.md#-google-cloud-run-serverless-deployment) for full deployment instructions).*

## 9. Frequently Asked Questions & Troubleshooting

### Q: Why is my PDF download showing styled typography instead of raw text?
**A**: The new PDF generator uses ReportLab with executive typography styles, auto-detecting section headers, contact bars, and indented bullets for corporate ATS compliance.

### Q: Can I run this completely offline without an API key?
**A**: Yes. All agents include robust offline heuristic fallbacks that analyze local resume text, regex date anchors, and standard engineering taxonomies without making external API calls. Adding a `GOOGLE_API_KEY` activates Live Google Search Grounding, Gemini 2.5 embeddings, and conversational AI interview grading.
